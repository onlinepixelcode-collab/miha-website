# MiHa Eatery — website

Multi-page, responsive site for MiHa Eatery (Melrose Arch, Centurion and MiHa X Lenasia).

- Pages are generated by `node build.mjs` from shared parts (`build.mjs`, `content.mjs`, `parts/`).
- Preview locally with `node serve.mjs` and open http://localhost:4173
- Styles: `style.css` · Motion: `main.js` · Concierge chat: `concierge.js` · Booking steps: `booking.js`
